# LuchaDB data archive

This repository contains human-readable yearly exports of the event and match
information maintained at [LuchaDB](https://www.luchadb.com/). Splitting the
archive by year keeps the files practical to download, browse, and preserve.

Each file begins with a description of the export format and the symbols used
within it.
